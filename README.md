# An MBSE-Based Framework for the Design and Analysis of Nanosatellite Electrical Power Systems

- See `final_report/main.pdf` for the final report.
- See `tutorial_videos` for, like the name implies, tutorial videos on how to use the framework via Python REPL or the GUI (`framework/gui`).
- Run `cd framework/gui && npm run start` to start the GUI.
- Read `framework/models` to understand how the MBSE models are implemented as pure Python classes.
