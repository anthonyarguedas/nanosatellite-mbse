# Search-support artifacts

This directory contains reproducibility artifacts for the frozen SLR search strategy. Protocol version 1.6 was prospectively amended, frozen, and authorized on 2026-08-10; it retains the version-1.3 genericity methodology and version-1.5 source/completeness design, admits completed graduate theses/dissertations, and synchronizes fourteen independently searched sources/collections through twelve interfaces, including exact-database PQDT Global and whole-index OATD. Dated pilot logs document interface, implementation, and no-screening validation only: they are **not** candidate/evidence searches and must not be used as discovery results. Every final source run must use clean version-1.6 storage and the common 2026-08-10 evidence cutoff.

## Authorized scripted sources

Every permitted adapter in `/Users/antho/agent-tools/academic-research/skills/academic-search/scripts` is represented: `search_scopus.py`, `search_ieee_xplore.py`, `search_compendex.py` (paired Compendex+Inspec), `search_wiley_online_library.py`, `search_springer_link.py`, `search_proquest_aerospace.py`, `search_aiaa_arc.py`, `search_iaf_digital_library.py`, `search_esa_indico.py`, and `search_ntrs.py`. Web of Science Core Collection, PQDT Global, and OATD are additional mandatory normal-interface sources. No PQDT/OATD **production retrieval** adapter is currently authorized. Review-local `tools/search_proquest_pqdt_global.py` and `tools/oatd_basic_count_gate.py` are implemented and hash-pinned in the current validation state, not yet version-control promoted; they are aggregate-only, accept only frozen version-1.6 query IDs, deliberately reject native zero, serialize no records, and cannot create merge input or satisfy the open pagination/export/identity gates. The aerospace adapter must never be relabelled as PQDT. `search_arxiv.py`, `search_semantic_scholar.py`, and `search_google_scholar.py` are explicitly forbidden.

## Tools

- `tools/api_pagination_reconcile.py` and `tools/test_api_pagination_reconcile.py` — Retrieve/reconcile complete Scopus or IEEE API snapshots and provide 17 offline privacy/contract regressions. The current driver removes direct, encoded, nested, fragment, malformed, and authority-userinfo session/credential context before persistence while retaining benign query components; it rejects incomplete or order-unstable results.
- `tools/concept_matcher.py` — Deterministically matches dictionary terms in text/JSON and runs the matcher fixtures; its local T2 tag requires a standalone model/models/architecture/architectures anchor within the same route.
- `tools/iaf_title_abstract_matcher.py` and `tools/test_iaf_title_abstract_matcher.py` — Offline-tested, version-locked IAF local route wrapper. Production input is the official adapter's top-level `results` envelope and every local decision preserves its unique non-empty `paperId`; synthetic direct records require the explicit fixture-only flag. Its provenance-only subtypes are `P AND M_high-specificity` and `P AND M_broad AND R`, not IAF B1/B2 searches.
- `tools/esa_indico_harvest_match.py` and `tools/test_esa_indico_harvest_match.py` — Harvest the whole ESA Indico instance with canonical anonymous transport, strict root/child/event/contribution identity and coverage controls, bounded same-origin attachment redirects, extraction, route-isolated matching, and 17 offline transport/identity regressions.
- `tools/esa_indico_rematch.py` — Re-runs ESA matching from an already harvested local archive without downloading attachments again.
- `tools/esa_genericity_route_regression.py` — Checks version-1.3 genericity-route behavior against synthetic route fixtures.
- `tools/search_strategy_lint.py` — Static version-1.6 checks for 99 physical source-native blocks plus 11 normative PQDT aliases (110 logical blocks); the 22-entry pinned thesis-source manifest and six validation files; complete A3, finite OATD forms and T2/V1/O1; NTRS 940-cell/C1-anchor arithmetic; fourteen-source/twelve-interface authorization; exact accounting of all 13 external `search_*.py` source scripts; and distinct merger aliases/tests for ATAI, PQDT, and OATD.
- `tools/oatd_basic_count_gate.py` and `tools/search_proquest_pqdt_global.py` — Review-local, loopback-CDP, aggregate-only, non-production wrappers. Both read the pinned manifest once as bytes, hash/decode those same bytes, map ordinary runtime failures to fixed-code `source_total: null` artifacts, and publish no-clobber owner-only `0600` JSON artifacts. OATD does not scan broad headings (`h1`/`h2`); PQDT requires exactly one visible unchecked **Full text** control and two same-owned-page PQDT-only selector assertions. Absent/hidden/type/degree/access limiter proof and external ABA remain explicit live `PQDT-02` residuals.
- `tools/test_oatd_basic_count_gate.py`, `tools/test_search_proquest_pqdt_global.py`, and `tools/test_thesis_source_count_gate_fixtures.py` — **47** synthetic offline regressions (`18` OATD + `25` PQDT + `4` shared fixture) for frozen query registries, exact source/control state, null failures, privacy, immutable owner-only output, and shared record-free fixtures. Exact current validation-state wrapper/test/fixture SHA-256 values are recorded in [`2026-08-11-thesis-source-validation-round-2.md`](subagent-logs/2026-08-11-thesis-source-validation-round-2.md).
- `tools/final_run_governance_lint.py` — Current-byte SHA-256 `9ef6622a0955ad647536c83e443391abf83aa6afbd5c217ef5904db4a86a8588`; validates the 14-source/12-interface crosswalk and both final-run schemas against two positive and eight negative in-memory contracts. The two added schema-valid negatives prove that duplicate source IDs and a valid-but-wrong OATD interface/PRISMA mapping fail crosswalk binding. Optional `--manifest PATH` schema-validates and binds any future real manifest to the exact 14 IDs each once, exact interface/PRISMA mappings, and the current crosswalk byte hash, without creating a real manifest/root or executing a source query.
- `tools/wos_ris_gate.py` and `tools/test_wos_ris_gate.py` — Standard-library-only private RIS integrity, cited-reference-sidecar, validation, and two-pass reconciliation tooling plus dedicated synthetic regressions. They have no browser or network capability and never emit source values in control artifacts.
