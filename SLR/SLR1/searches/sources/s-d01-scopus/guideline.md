## 2. Interface and field behavior

- **[observed]** Advanced Search exposes `TITLE-ABS-KEY` (“Doc Title, Abstract, Keyword”), `TITLE`, `ABS`, `AUTHKEY`, `KEY`, `INDEXTERMS`, `LANGUAGE`, `PUBYEAR`, `PUBDATETXT`, `SRCTYPE`, `INDEX`, `EID`, and `DOI`. This draft uses `TITLE-ABS-KEY` for every mandatory free-text block.
- **[observed_and_documented]** The Advanced Search UI accepted all direct-cell queries in `translation-spec.json`. Scopus Support’s current Advanced Search guidance describes straight quotes as loose/approximate phrases and braces as exact phrases. In the scoped live test, loose hyphenated and spaced model-based-systems-engineering phrases each displayed 61 results, while the corresponding exact-brace hyphen phrase displayed 47. See the pilot count ledger.
- **[observed_and_documented]** The scoped parenthesized and unparenthesized Boolean diagnostics each displayed 22 results, consistent with the current official precedence guidance. Every reusable query nevertheless retains explicit parentheses; no final procedure may rely on precedence.
- **[observed_and_documented]** Current official guidance says non-exact English/scientific-term searching can use lemmatization and hyphen punctuation can normalize outside an exact phrase. The scoped hyphenated and separated population tests each displayed one result, but this does **not** justify dropping either normative spelling. All 20 population forms remain literal in the queries.
- **[observed]** `nanosat*` was accepted and displayed the same scoped total (6) as the four contiguous literal forms with `SysML`. This does not test separated or hyphenated forms, nor all contexts. No `nanosat*` substitution is used.
- **[untested]** Bare `MBSE` and `MBSE*` had the same scoped total (53), but count equality cannot prove standalone-token boundaries or exclude substring matches. The final translation retains explicit bare acronym tokens and must not claim a general token-boundary proof.
- **[observed_documented_and_human_approved]** `W/6` syntax was accepted in pair-bearing cells. Current Elsevier Support guidance (accessed 2026-08-22; updated 2024-08-15 and 2025-10-20) defines `W/n`/`PRE/n` only as within/preceding by a specified distance; it does not say whether `n` counts endpoints, positions, or intervening lexical tokens. `W/6` is therefore not claimed as an exact five-intervening-token translation. Under H2, the review owner approved it as the protocol-permitted conservative same-field fallback: it cannot lose a pair with at most five intervening tokens under either common convention, but may admit one extra intervening token if `n` counts intervening tokens.
