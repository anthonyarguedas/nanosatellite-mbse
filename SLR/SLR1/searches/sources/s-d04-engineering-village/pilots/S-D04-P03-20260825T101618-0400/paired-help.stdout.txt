Run the single P03 paired Compendex/Inspec diagnostic event. This is a bounded
attached diagnostic, not a final-search runner. It is intentionally separate
from the route projection: operation 1 is performed by
``engineering_village_route_probe.py`` and this utility is operation 2. The
one logical paired event contains exactly two explicitly counted component
requests, one to Compendex and one to Inspec. Existing Engineering Village
adapter calls are made sequentially so that only one adapter-owned page exists
at a time. The adapter results are inspected only for safe count, selection,
control, and provenance metadata. Bibliographic records are never written. A
successful component request is capped at one rendered page and one record;
this event must stop after count/control evidence and must never become full
retrieval.

options:
  -h, --help            show this help message and exit
  --execute             permit the two diagnostic adapter requests
  --attempt-id ATTEMPT_ID
  --cdp-url CDP_URL
  --query-file QUERY_FILE
  --pilot-date PILOT_DATE
  --output-path OUTPUT_PATH
  --timeout-seconds TIMEOUT_SECONDS
  --adapter-page-delay-seconds ADAPTER_PAGE_DELAY_SECONDS
  --inter-database-delay-seconds INTER_DATABASE_DELAY_SECONDS
  --adapter-dir ADAPTER_DIR
