usage: engineering_village_route_probe.py [-h] [--execute] [--cdp-url CDP_URL]
                                          [--timeout-seconds TIMEOUT_SECONDS]
                                          [--stabilization-interval-seconds STABILIZATION_INTERVAL_SECONDS]
                                          --output-path OUTPUT_PATH

One-owned-page Engineering Village public paired-Expert route probe. The
utility is a route/DOM diagnostic, not a search. It attaches only to an
explicit loopback CDP endpoint, opens one distinct sibling page, makes one
normal navigation to the public paired Expert route, and returns a rights-safe
boolean/count receipt. It never retains a raw URL, page body, target ID,
credential, cookie, query text, or source record. ``--execute`` is
deliberately opt-in so ordinary offline tests and parser checks make no source
action. A browser-lease wrapper can pass the explicit CDP endpoint and opt in
only after its own preflight has completed.

options:
  -h, --help            show this help message and exit
  --execute             permit one source navigation
  --cdp-url CDP_URL
  --timeout-seconds TIMEOUT_SECONDS
  --stabilization-interval-seconds STABILIZATION_INTERVAL_SECONDS
  --output-path OUTPUT_PATH
