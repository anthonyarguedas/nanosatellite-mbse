Search whole-platform Springer Nature Link through one owned local Chrome
page. It does not automate login, CAPTCHA, challenges, or access controls.

options:
  -h, --help            show this help message and exit
  --query QUERY         Exact Link Keywords query
  --limit LIMIT
  --year-start YEAR_START
  --year-end YEAR_END
  --date-start DATE_START
                        Inclusive YYYY-MM-DD; requires --date-end
  --date-end DATE_END   Inclusive YYYY-MM-DD; requires --date-start
  --max-pages MAX_PAGES
  --passes {1,2}        1 diagnostic pass or 2 reconciled ordered canonical-
                        path passes
  --timeout, --browser-timeout TIMEOUT_SECONDS
  --page-delay-seconds PAGE_DELAY_SECONDS
  --language {En}
  --sort {relevance,newestFirst,oldestFirst}
  --count-only          Validate controls and an exact total without retaining
                        card text or opening content pages.
  --require-complete    Require a visible owned page, exact dates, the
                        1,000-record cap, two passes, and full card exhaustion
                        before normal publication.
  --cdp-url, --browser-cdp-url CDP_URL
                        Loopback Chrome DevTools URL for the authorized local
                        browser (default: http://127.0.0.1:9222).
  --fresh-browser       Opt out of the default local Chrome session and launch
                        a fresh browser.
  --target-id TARGET_ID
                        Exact authorized Link Chrome target used only to prove
                        its session; the user tab remains untouched. Requires
                        --cdp-url.
  --headless            Launch the explicit --fresh-browser instance
                        headlessly (rejected by --require-complete).
  --chrome-executable CHROME_EXECUTABLE
                        Optional local Chrome binary or .app path for --fresh-
                        browser.
  --output-path OUTPUT_PATH
  --csv-output-path CSV_OUTPUT_PATH
                        Optional normalized merge-compatible CSV
  --native-csv-output-path NATIVE_CSV_OUTPUT_PATH
                        Optional diagnostic, unreconciled Link CSV (cap 1,000;
                        no normal JSON/CSV publication; rejected by --require-
                        complete).
