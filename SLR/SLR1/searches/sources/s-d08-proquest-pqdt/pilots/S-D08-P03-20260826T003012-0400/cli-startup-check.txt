Search PQDT Global through normal rendered ProQuest UI and collect bounded
metadata plus abstracts. Requires normal institutional browser access when
gated.

options:
  -h, --help            show this help message and exit
  --query QUERY         ProQuest Command Line Search query, e.g. NOFT(CubeSat)
  --limit LIMIT         Maximum records to collect (default: 20)
  --max-pages MAX_PAGES
  --timeout TIMEOUT
  --page-delay-seconds PAGE_DELAY_SECONDS
  --detail-delay-seconds DETAIL_DELAY_SECONDS
  --count-only          Return the reconciled rendered PQDT total without
                        retaining records; the diagnostic is never reportable
                        or mergeable.
  --require-complete    Require two complete rendered pagination passes with
                        identical ordered numeric ProQuest document IDs;
                        cannot be combined with --count-only.
  --cdp-url CDP_URL     Loopback Chrome DevTools endpoint for the authorized
                        local browser (default: http://127.0.0.1:9222)
  --fresh-browser       Opt out of the default local Chrome session and launch
                        a fresh browser.
  --headless            Launch the explicit --fresh-browser instance
                        headlessly.
  --chrome-executable CHROME_EXECUTABLE
                        Optional local Chrome binary or .app path for --fresh-
                        browser.
  --output-path OUTPUT_PATH
  --csv-output-path CSV_OUTPUT_PATH
                        Optional normalized merge-compatible CSV path
