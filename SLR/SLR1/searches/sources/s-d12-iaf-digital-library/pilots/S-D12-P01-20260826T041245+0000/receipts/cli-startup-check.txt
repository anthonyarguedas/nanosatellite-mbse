Search public full IAF Digital Library metadata and abstracts

options:
  -h, --help            show this help message and exit
  --query QUERY         IAF public-search expression
  --limit LIMIT         Maximum records to save (1-5000; default: 20)
  --event-code EVENT_CODE
                        Optional explicit IAF event scope (for example
                        GLEX-2025); the default searches the full library
  --year-start YEAR_START
                        Inclusive client-side record publication-year lower
                        bound
  --year-end YEAR_END   Inclusive client-side record publication-year upper
                        bound
  --max-pages MAX_PAGES
                        Maximum 50-record search pages to inspect (1-100;
                        default: 3)
  --timeout TIMEOUT_SECONDS
                        Per-request timeout in seconds (maximum: 300; default:
                        20)
  --request-delay-seconds REQUEST_DELAY_SECONDS
                        Polite delay before each HTTP request after the first
                        (maximum: 60; default: 0.25)
  --retries RETRIES     Retries for transient 429/5xx/network failures (0-5;
                        default: 2)
  --count-only          Inspect a public search page only; never report-ready
                        and returns no detail records
  --output-path OUTPUT_PATH
                        Path for the complete JSON artifact
  --csv-output-path CSV_OUTPUT_PATH
                        Optional normalized merge-compatible CSV path
