Search NASA NTRS through its normal rendered first-party browser UI; it does
not automate access controls or download PDFs.

options:
  -h, --help            show this help message and exit
  --query QUERY         NTRS text entered through the visible normal search
                        control
  --limit LIMIT
  --year-start YEAR_START
                        Inclusive legacy publication-year lower bound
  --year-end YEAR_END   Inclusive legacy publication-year upper bound
  --date-start DATE_START
                        Exact inclusive publication date (YYYY-MM-DD), subject
                        to visible UI validation
  --date-end DATE_END   Exact inclusive publication date (YYYY-MM-DD), subject
                        to visible UI validation
  --max-pages MAX_PAGES
  --timeout, --browser-timeout TIMEOUT_SECONDS
  --page-delay-seconds PAGE_DELAY_SECONDS
  --detail-delay-seconds DETAIL_DELAY_SECONDS
  --count-only          Validate the first rendered result page and total
                        without retaining records
  --skip-full-abstracts, --no-full-abstracts
                        Keep only rendered search-card metadata and skip
                        canonical citation-detail visits
  --require-complete    Require exactly two exhaustive rendered canonical-ID
                        passes with stable order, totals, ranges, and controls
  --cdp-url, --browser-cdp-url CDP_URL
                        Loopback Chrome DevTools endpoint for the authorized
                        local browser (default: http://127.0.0.1:9222)
  --fresh-browser       Explicitly opt out of the default local CDP browser
                        and launch a fresh local Chrome instance
  --target-id TARGET_ID
                        Exact NTRS Chrome target used only as
                        authorization/context proof; it is never navigated or
                        closed
  --headless            Launch the explicit --fresh-browser instance
                        headlessly
  --chrome-executable CHROME_EXECUTABLE
                        Fresh-browser Chrome binary or .app path; requires
                        --fresh-browser
  --output-path OUTPUT_PATH
  --csv-output-path CSV_OUTPUT_PATH
