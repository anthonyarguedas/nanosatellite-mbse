## Corrective integration decisions

### API provenance and privacy

Independent security review confirmed real serialization defects: the Scopus client put its key in a URL, and several runtime paths retained session/search URL context. Corrected changes were applied in the main repository and `agent-tools`: Scopus now uses only `X-ELS-APIKey` while retaining private dotenv support; source URL/error handling is fail closed; benign query components remain; sensitive direct, encoded, nested, fragment, authority-userinfo, and malformed URL context is removed before persistence.

- in-memory scan found no runtime credential in any artifact or captured stream.

### Engineering Village

### Web of Science

Browser automation was not promoted. The accepted repository additions are a manual normal-interface procedure plus standard-library-only offline RIS/sidecar/reconciliation tooling and seven synthetic tests. Native pilot RIS and sidecars remain private and excluded.

### NTRS orchestrator

The successful 280-cell source gate is retained. The earlier proposed 1,897-line aggregate-only orchestrator remains rejected and is not revived. Its missing final-adapter subgate is now closed offline by the smaller package-owned `ntrs_final_matrix.py` and `test_ntrs_final_matrix.py`: literal construction verifies 180 core + 250 G + 510 C1 = 940; every source cell uses fixed 100-row pagination, stable total/terminal arithmetic/unique IDs, one permitted offset-zero restart, and two complete ordered-ID passes; source responses are rejected before persistence if they carry cookie/auth/sensitive direct, encoded, nested, fragment, or userinfo URL context; output is owner-only, atomic, and all-or-nothing; and local E/T2/V1/O1 tagging occurs only after source-ID union deduplication with field-local text, never URL/ID/cross-field matching. The suite exercises source cardinality, multi-page arithmetic, restart, explicit 940-cell native zero, non-candidate preflight, partial-matrix refusal, source-context privacy, and tag semantics. This is an offline implementation closure only: immutable promotion, a clean live 940-cell final run, and the remaining G03 source/procedure/privacy conditions are still required.
