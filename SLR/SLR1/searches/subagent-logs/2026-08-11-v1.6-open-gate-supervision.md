## Corrective integration decisions

### API provenance and privacy

Independent security review confirmed real serialization defects: the Scopus client put its key in a URL, and several runtime paths retained session/search URL context. Corrected changes were applied in the main repository and `agent-tools`: Scopus now uses only `X-ELS-APIKey` while retaining private dotenv support; source URL/error handling is fail closed; benign query components remain; sensitive direct, encoded, nested, fragment, authority-userinfo, and malformed URL context is removed before persistence.

A second provenance review rejected a hash-only refreeze after finding deeper encoded/userinfo bypasses. The final correction added 17 durable privacy/reconciliation tests and bound the active template to the corrected driver. The authoritative post-redaction live rerun passed:

- reconciler SHA-256: `2e5ffe894d83dc80186a85f171aa47120dac0f9cc6778045a2324257bad8db5e`;
- template SHA-256: `cca156fd09b1c63da8522d483e906acc6d5258e508b1429b7147d772a7e6b0aa`;
- privacy scan: 12 raw, 16 request, four normalized, and two merge artifacts; zero findings;
- in-memory scan found no runtime credential in any artifact or captured stream.

### Engineering Village

Independent review identified a bounded Select2 selector/wait defect but rejected any terminal-small-set exemption from explicit 100/page. The prospective selector patch was applied to `agent-tools`; 35 adapter tests and 17 merger tests passed. A fresh live rerun still exposed only 25/page and therefore remained failed closed. This preserves the frozen control rather than retroactively accepting two rendered rows.

### IAF

Independent review invalidated the first V16-IAF-01 wrapper because it mishandled the adapter envelope/stable ID, implemented uncoupled T2, and omitted strict subtype fixtures. The corrected wrapper and fixtures were applied only after focused tests, Ruff, strategy lint, external IAF tests, and retained ESA fixture reruns passed.

### ESA

The first transport patches were rejected for permissive authority checks, cookie/redirect handling, incomplete identity/count guards, and partial-prefix behavior. Corrected local and external patches were integrated and rerun offline, followed by a fresh bounded live preflight using only newly observed root state. The earlier unpatched live sample is not the authoritative transport result.

### Web of Science

Browser automation was not promoted. The accepted repository additions are a manual normal-interface procedure plus standard-library-only offline RIS/sidecar/reconciliation tooling and seven synthetic tests. Native pilot RIS and sidecars remain private and excluded.

### NTRS orchestrator

The successful 280-cell source gate is retained. A proposed 1,897-line aggregate-only 940-cell orchestrator was independently rejected for unpinned ordered semantics, mutable live controls, an inaccurate caller-supplied-HMAC claim, incomplete failure arithmetic, missing pair-exclusive overlap fields, and unrelated README drift. The reviewer staged a corrected 16-test patch, but it is **not promoted in this change set**: it remains a large duplicate reconciliation implementation and still is not the final normalizing adapter. Before promotion, refactor it around a reviewed common reconciliation primitive, fail fast on a terminal cell/source failure, and independently review the final metadata/tagging boundary.
