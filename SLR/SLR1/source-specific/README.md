# Source-specific search guidelines

The review tracks 15 sources through 13 web interfaces.

| Source or collection | Interface | Guideline |
|---|---|---|
| Scopus | Scopus | [Scopus](scopus/source-specific-guidelines.md) |
| Web of Science Core Collection | Web of Science | [Web of Science](web-of-science-core-collection/source-specific-guidelines.md) |
| IEEE Xplore | IEEE Xplore | [IEEE Xplore](ieee-xplore/source-specific-guidelines.md) |
| arXiv | arXiv | [arXiv](arxiv/source-specific-guidelines.md) |
| Compendex | Engineering Village | [Compendex](compendex/source-specific-guidelines.md) |
| Inspec | Engineering Village | [Inspec](inspec/source-specific-guidelines.md) |
| Wiley Online Library | Wiley Online Library | [Wiley](wiley-online-library/source-specific-guidelines.md) |
| Springer Nature Link | Springer Nature Link | [Springer](springer-nature-link/source-specific-guidelines.md) |
| Advanced Technologies & Aerospace Index | ProQuest Platform | [ATAI](advanced-technologies-aerospace-index/source-specific-guidelines.md) |
| ProQuest Dissertations & Theses Global | ProQuest Platform | [PQDT Global](pqdt-global/source-specific-guidelines.md) |
| AIAA Aerospace Research Central | AIAA ARC | [AIAA ARC](aiaa-arc/source-specific-guidelines.md) |
| IAF Digital Library | IAF Digital Library | [IAF](iaf-digital-library/source-specific-guidelines.md) |
| Open Access Theses and Dissertations | OATD | [OATD](oatd/source-specific-guidelines.md) |
| ESA Indico | ESA Indico | [ESA Indico](esa-indico/source-specific-guidelines.md) |
| NASA Technical Reports Server | NASA NTRS | [NASA NTRS](nasa-ntrs/source-specific-guidelines.md) |

Compendex and Inspec use one paired Engineering Village event while retaining separate records and counts. The two ProQuest sources use separate events. Only Scopus and Web of Science use PSR and forward citation searches.

Keep the master files under [`template/`](template/). Search artifacts are created only when a pilot or final event runs.
