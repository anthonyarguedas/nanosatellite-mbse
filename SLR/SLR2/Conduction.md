## Search Results

Procedure:
- Run the query (with inclusion/exclusion criteria included if possible)
- Count hits
- Select included papers
- Export as CSV
- Count included papers

In IEEE Xplore the queries are pasted into the main search bar, and once results load the date filter can be applied. No publication type filters are applied since by default they load only journal and conference articles. Sorted by releavance.

In Scopus all filters are embedded in the query string so it is simply pasted into the Advance Search bar. Sorted by relevance.
