\paragraph{Custom scene scope and maturity.}
PA-CDT retains OpenUSD, Omniverse Kit, Isaac and FMI. The mandatory CPU profile includes offline controller SIL, supplied-data replay and one pinned FMI/FMU master path. OpenUSD maps accepted model IDs to prims, units and frames. Omniverse provides decision-specific scene review. Isaac adds motion/contact only when it affects EPS demand or generation. Python binds USD/FMI/EPS/battery results through an explicit clock/master. GPU, driver and Kit/Isaac dependencies apply only to that activated profile. All combined mappings remain proposed. Scenes establish no validated electrical, thermal, aging or EMC prediction. Physical controllers, live telemetry, HIL and autonomous control remain later external work.

All candidates need sourced model data, qualified references and explicit RAM, calibration, software and safety methods. Module names give no implementation credit. Related source accounts are not independent replications.
