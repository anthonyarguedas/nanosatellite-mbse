All occurrences have a response. External outcomes remain bounded: redesign cost, physical defects, spacecraft RAM, replica use and non-EPS acceptance depend on mission artifacts/operations. Coverage checks flag orphan sources, unknown IDs, missing allocations/contracts/procedures and unsupported derivations. They check design records. Implementation, stakeholder validation, MOEs, model adequacy, target compatibility and facility authorization remain open. Changed requirements/models retain revision/impact/successor history. Separate EPS specification trees link mission/component requirements to EPS evidence. Framework operation satisfies no EPS voltage, thermal or software requirement.
