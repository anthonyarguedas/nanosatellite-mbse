Checks over assigned components

Link COTS selections to this requirement in the COTS table. Use Requirement values as the method source. The last argument names a target parameter owned by this requirement, including its unit.

all_assigned("Battery", "nominal_voltage", "==", target_voltage)

sum_assigned("SolarArray", "maximum_power", ">=", target_power)

count_assigned("Battery", cots_only=True) <= max_batteries

The sum includes each selection's quantity. Counts use distinct entries, or represented units with by_quantity=True. An empty count is zero. Empty property selections and missing facts remain pending. Numeric equality accepts abs_tol in the target unit and rel_tol. Both default to zero.
